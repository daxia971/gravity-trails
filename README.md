# 引力星途 · Gravity Trails

一个烧脑的引力弹道解谜游戏：发射彗星，借行星引力弯曲弹道命中目标星。零依赖单文件 HTML。

**在线试玩**: https://daxia971.github.io/gravity-trails/

## 这个游戏的特别之处

- 🪐 **真实引力模拟**：平方反比引力，行星会把你的弹道拉成弧线、回旋甚至轨道——后期关卡限制发射力度，直线根本到不了，必须打**引力弹弓**
- ⏳ **时间只在彗星飞行时流动**（SUPERHOT 式）：行星轨道每次发射都从同一相位重演，这个宇宙完全确定——失败只因瞄准差了半度，与运气无关
- 🎯 **狙击手模式**：拖拽粗瞄后，方向键微调 0.5°、力度 ±0.1，回车发射；手机端有长按连调按钮
- 🕳️ 黑洞会吞噬彗星，但它的强引力也是过关工具（黑洞弹弓关）
- ✦ 每关 3 枚星尘 + 标准发射数，三星评价，进度本地存档

## 20 个手工关卡，每一关都经过求解器验证

基础篇 12 关 + 进阶篇 8 关。进阶篇引入三个新机制：

- ☀️ **斥力星**：不吸反推的白矮星，可以是风、也可以是盾（「盾与矛」把它架在目标头顶）
- 🛰️ **移动黑洞 / 移动目标星**：黑洞在轨道上巡逻、目标星绕轨飞行——瞄准时会显示目标的金色"未来轨迹"，
  和你的弹道虚线在**同一时间轴**上，两条时间线必须在同一刻相交（打提前量拦截）
- 🔭 **短预览**：最难的几关只给你看前 300~400 步的预览，剩下的弧线靠推演

开发时用暴力求解器（360° × 力度网格全扫描）验证每关可解，并以"解密度"控制难度曲线：
从第 1 关的教学难度一路压到「黑洞弹弓」的 **0.25%**（一万次随机发射只有 25 次能过）。
求解器就内置在页面里，控制台 `solveLevel(关卡序号)` 可自行验证。

**关卡门控**：必须通关当前关才解锁下一关；已通关的关卡随时可以回去刷三星。

## 操作

- 电脑：拖拽瞄准松手发射 · ←→↑↓ 微调 · 回车发射 · R 清除瞄准 · 飞行中点击中止
- 手机：拖拽瞄准 + 底部按钮微调/发射（横屏体验更佳）

## 技术

纯 HTML + Canvas。预览轨迹、实际飞行、求解器共用同一个纯函数模拟器，保证「预览即现实」。
音效 WebAudio 现场合成，无任何外部资源。
